# Pay-Calculator

## Purpose of Program
This program is used to calculate the monthly salaries of employees.

## How to use
When you use the program it will ask the user whether they are part or full time then it will ask pay related questions. Then it will calculate monthly salary and print it our for the user.

## Example
```text
Enter employee type (full-time / part-time): Full-time
Enter base pay: 9000
Enter bonus: 500
Monthly Salary: $9500.0
```
## Different Cases
If the user does not put in the correct "full-time/part-time" input they will be asked to try again.
```text
Enter employee type (full-time / part-time): no
Invalid statement please try again.
Enter employee type (full-time / part-time):
```
